PHOTO GALLERY — INLINE ADMIN PREVIEW

Откройте index.html.

Что работает в демо:
- обычный посетитель видит только галерею;
- кнопка «Войти» находится прямо в шапке галереи;
- для демо можно ввести любые email/пароль;
- после входа галерея остаётся той же;
- появляются создание категории, добавление/редактирование/удаление альбомов;
- владелец видит кнопку «Администраторы»;
- можно выбрать локальные фотографии в окне редактирования (только на время текущего открытия страницы).

Важно:
Это визуальный прототип. Изменения пока не сохраняются после перезагрузки.
Настоящая авторизация, база, защищённые роли и серверное хранение фото будут следующим этапом.
Тестовые фотографии загружаются с picsum.photos, поэтому нужен интернет.
