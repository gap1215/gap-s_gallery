PHOTO ARCHIVE v10 — подключение Supabase

Что уже умеет v10 после подключения:
• настоящий вход по email + паролю;
• сессия сохраняется в браузере;
• категории сохраняются в Postgres;
• альбомы, их название, категория и тип доступа сохраняются в Postgres;
• посетитель без входа получает из базы только открытые альбомы;
• редактирование разрешено только owner/admin через RLS.

Что пока НЕ подключено:
• постоянное хранение самих фотографий (в v10 выбранные файлы живут до перезагрузки);
• пароль/приватная ссылка для просмотра закрытого альбома;
• приглашение новых администраторов.
Это следующие этапы.

НАСТРОЙКА
1. Создайте проект в Supabase.
2. Откройте Authentication → Users и создайте пользователя-владельца с вашим email и паролем.
3. Скопируйте UUID этого пользователя.
4. Откройте SQL Editor, вставьте содержимое файла supabase-setup.sql и выполните его.
5. После этого выполните отдельно строку, подставив ваш UUID:
   insert into public.profiles(id, role) values ('ВАШ_UUID','owner');
6. Откройте Project Settings → API.
7. В js/config.js вставьте Project URL и Publishable key (или anon key проекта, если интерфейс проекта показывает его под старым названием).
8. Откройте сайт через локальный веб-сервер/хостинг и войдите через кнопку «Войти».

ВАЖНО
Никогда не вставляйте service_role key в js/config.js или другой файл сайта. Он обходит RLS и должен оставаться только на доверенном сервере.
